# TLiner

TLiner is a way to connect editing teams — self-hostable video review and production management: frame-accurate comments, voice notes, paint-over annotations, quick trims, tasks/kanban and a client portal. Runs locally (desktop app), on a LAN, or on a cheap VPS.

**Status:** pre-development. The build spec is in [docs/SPEC.md](docs/SPEC.md).

## Getting started with Claude Code

1. Clone this repo.
2. Open Claude Code in the repo folder.
3. Say: `Read CLAUDE.md and docs/SPEC.md, then start building M0.`

Progress is tracked in [docs/PROGRESS.md](docs/PROGRESS.md).
